# Migrating from 0.6 to 0.7

0.7 is a minor release of a pre-1.0 crate, so it carries breaking changes. This page gathers the
ones that need a code change. Each crate's `CHANGELOG.md` lists everything, in more detail.

## Rich text editor

The rich text editor moved from `blinc_layout` to `blinc_cn`, so that its toolbar can use the cn
components. Change the import path. The functions, types and CSS classes keep their names.

```rust
// 0.6
use blinc_layout::widgets::rich_text_editor::{RichDocument, rich_text_editor, rich_text_state};

// 0.7
use blinc_cn::components::rich_text_editor::{RichDocument, rich_text_editor, rich_text_state};
```

With the `blinc` facade crate, the path is `blinc::cn::components::rich_text_editor`. Its rules
are part of `CN_STYLES`, so a theme bundle that sets only the layout stylesheet must add
`CN_STYLES` to style the editor.
