The self-contained highlight.js 10.1.1 build is shared with mdBook's code
highlighting, with an ES module export added for the component pages. It includes
Rust and CSS grammars. The upstream BSD 3-Clause license is in LICENSE.

`format.js` adds Rust call/type/punctuation tokens and selectable line numbers.
Its presentation follows the landing page's syntax palette, typography and code
surface. The side editor uses the same formatter as the displayed examples.

https://github.com/highlightjs/highlight.js/tree/10.1.1
