Get started

Your first Blinc app.

Install Blinc’s component library, add the default Hybrid theme, and build an interactive Rust interface.

1. Create a Rust project

Use a Rust toolchain compatible with Blinc 0.6.0 (Rust 1.89 or newer). Create a binary crate:

cargo new my-blinc-app
cd my-blinc-app

Add these dependencies to Cargo.toml:

Cargo.toml
[dependencies]
blinc_app = "0.6"
blinc_cn = "0.6"
blinc_core = "0.6"
blinc_layout = "0.6"
blinc_theme = "0.6"

2. Build a component

Replace src/main.rs with this example. The label is a Computed derived from a Signal; clicking updates the existing button. Styles come from CSS.

src/main.rs
{{INSTALL_SOURCE}}

HybridTheme::bundle().with_css(CN_STYLES) installs the shared component theme. Application CSS follows that layer and can override its documented selectors and variables.

3. Run it

cargo run

Blinc opens a native window. These catalog examples start in Hybrid dark mode. Choose ColorScheme::Light for a light interface.
